# V2.2 检索问题与优化记录

## 当前状态

V2.2 保持现有检索实现与参数不变，以下问题作为后续 RAG 优化样本记录。

## 已知问题

### 1. 装修贷款材料未采用

- 测试问题：`装修贷款需要房产证吗？`
- 相关内容：消费贷装修用途需提供装修合同、预算清单、房屋权属或使用关系证明。
- 检索结果：正确片段排名第 1，距离 `0.8136`，高于当前阈值 `0.7`，未进入回答上下文。
- 问题类型：口语表达与标准业务术语不一致，且“房产证”与住房贷款内容产生语义竞争。

### 2. 可疑转账处置要求未采用

- 测试问题：`行内对可疑转账有什么处置要求？`
- 相关内容：异常转入核查、账户管控及异常交易核查 SOP。
- 检索结果：相关片段进入 Top-5，最高相关候选距离 `0.7483`，仍高于当前阈值 `0.7`，未进入回答上下文。
- 问题类型：用户概括性表达与文档中的“异常转入、异常交易核查、账户管控”等标准术语存在差异。

## 后续优化方案

1. 基于固定评估集校准距离阈值，避免相关候选因统一经验阈值被误拒绝。
2. 精简 QA 与 Excel 检索文本，将治理字段保留在 metadata，减少长片段语义稀释。
3. 评估 BM25 与向量混合召回，提高专业术语、关键词和口语表达的匹配稳定性。
4. 扩大初始候选集并增加轻量重排序，最终选择 3～5 个高相关片段。
5. 评估受约束的领域查询规范化，保留原问题并补充标准业务术语，禁止改变原始意图。
6. 使用 Recall@K、MRR、nDCG 和引用正确率验证优化效果，同时记录延迟变化。
